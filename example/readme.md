This folder contains example usage of the library

All the examples rely on the following 3 environment variables being set:

- RBX_OC_TASKS_API_KEY
- RBX_OC_TASKS_UNIVERSE_ID
- RBX_OC_TASKS_PLACE_ID

Tasks will error if any are missing

If you are having issues with assertions failing, run the
`run_error_handling.luau` example, it should print error information before
asserts are hit
